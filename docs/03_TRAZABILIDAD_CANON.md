# Procedencia, identidad visual y control del canon

## Regla principal

El libro infantil es una **adaptación exclusiva**. Nada de lo propuesto en bocetos se considerará un elemento oficial del universo Karmany Monsta ni del libro hasta aprobarse expresamente.

## Fuentes posibles

- Catálogo de Karmany Monsta v0.74 proporcionado para consulta inicial: puede orientar nombres/códigos, **no prueba apariencia visual** ni confirma relaciones entre personajes.
- Documentos e imágenes oficiales de otros proyectos Karmany: **sujetos a identificación, verificación de vigencia y autorización**.
- Nuevos bocetos para el libro: **concept art editorial no canónico** hasta aprobación.

No importar estadísticas, ataques, afinidades, biografías, nombres inventados ni relaciones al relato infantil.

## Para cada personaje humano

Registrar origen (`referencia_aprobada` o `nuevo_diseno_editorial`), condición infantil, nombre si está aprobado, imágenes de referencia autorizadas, rasgos distintivos aprobados y versión.

## Para cada Karmany

Registrar código/nombre si procede de un documento verificable, referencia visual aprobada o justificación de adaptación, rasgos que deben conservarse y estado editorial. **No inferir anatomía por el nombre.**

## Nuevas adaptaciones

Toda ilustración de prueba debe llevar en su ficha:
- `canonical_status: not_canonical_pending_approval`.
- Identificación de los conceptos inventados únicamente como **propuesta gráfica**, nunca como descripción oficial.
- Fecha, versión, fuente y decisión de aprobación si llega a existir.

## Restricciones adicionales

- Los recursos y las ilustraciones de terceros requieren derechos/permisos de uso claros antes de publicarse.
- El contenido de prueba no debe presentarse como arte final ni como personaje oficial de los videojuegos o juegos de mesa.
- Las decisiones aprobadas solo para este libro **no** modifican automáticamente el canon de Android, Forja de Resonancia o Blockchain.
