# Protocolo de dirección de criaturas: continuidad antes de producción

La definición de personajes es una **fase nueva de diseño importante** porque fija identidad visual reutilizable. No alterar arte aprobado ni decidir apariencia de forma implícita.

1. Se parte de los datos verificables del catálogo, sin atribuir estética a mecánicas de juego.
2. Cada Karmany propuesto tiene un ID de catálogo y una ficha visual vacía; la silueta es una **pregunta de diseño**, no un hecho.
3. Para reducir retrabajo, se crean primero 3 siluetas con alta diferencia de formas y se valida el nivel de calidad.
4. Antes de generar expresiones, poses o escenas repetidas, se produce **una ficha de modelo** estable.
5. La ilustración de una página usa la ficha aprobada y no improvisa patas, orejas, colas o marcas.
6. Si cambia una decisión anatómica, comprobar todas las páginas donde aparezca la criatura y solicitar regresión visual; no retocar a ciegas.
7. El estándar de acabado REF-ART-01 permanece invariable; solo varía complejidad de la actividad y número de participantes.
8. Mantener estados distintos: `aprobado_visual_pagina`, `aprobado_diseno_criatura`, `congruente_canon_externo` y `archivo_png_github_verificado`.
9. La versión de las primeras tres láminas no obtiene automáticamente identidad de catálogo. Si se decide ligarlas a uno, evaluar si requieren rediseño y **nueva aprobación**.
10. No generar P04 hasta validar el elenco y las fichas de los candidatos de esa página.
