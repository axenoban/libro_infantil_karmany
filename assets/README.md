# Estructura de producción visual

Este directorio almacenará las ilustraciones **cuando comience la fase de pruebas**. No hay arte aprobado todavía.

## Organización prevista

```text
assets/
  referencias/        # Referencias autorizadas y procedencia
  propuestas/          # Conceptos NO CANÓNICOS pendientes de revisión
  laminas/             # Originales aprobados y fichas de cada lámina
  exportaciones/       # PNG/PDF de revisión y posteriormente finales
  portada/             # 2–3 enfoques de portada para decisión
```

Las carpetas se crearán al incorporar archivos reales, evitando directorios vacíos ficticios.

## Reglas de nombres

- `LAM-001_v01_propuesta.png`
- `LAM-001_v01_fuente.svg` (cuando exista un original vectorial)
- `LAM-001_ficha.md`
- `COVER-01_v01_propuesta.png`

No sustituir un aprobado sin elevar versión y volver a validar. Conservar el original editable siempre que exista y registrar procedencia.
